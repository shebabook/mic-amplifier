# মাইক অ্যামপ্লিফায়ার

ব্রাউজারে মাইকের শব্দ বাড়িয়ে হেডফোনে শোনার ছোট অ্যাপ।

## ব্যবহার

1. `index.html` খুলুন (GitHub Pages বা যেকোনো স্ট্যাটিক হোস্টে)।
2. হেডফোন লাগান।
3. "শুরু করুন" চাপুন, মাইকের অনুমতি দিন।
4. ভলিউম স্লাইডার দিয়ে শব্দ বাড়ান/কমান (১–১৫ গুণ)।

## স্পিকার মোড (ব্লুটুথ স্পিকার)

ফোনকে মাইক্রোফোন বানিয়ে ব্লুটুথ স্পিকারে কথা বলতে চাইলে:

1. ব্লুটুথ স্পিকার কানেক্ট করুন।
2. **স্পিকার মোড** টিক দিন — এতে ইকো ক্যানসেলেশন চালু হয়, ফিডব্যাক (বিপ শব্দ) কমে।
3. ফোনটা স্পিকার থেকে দূরে রাখুন।
4. ভলিউম **১x থেকে** আস্তে আস্তে বাড়ান। বিপ শব্দ হলে ভলিউম কমান বা ফোনটা আরও দূরে নিন।

ব্লুটুথে কিছুটা ডিলে (দেরি) হতে পারে — এটা ব্লুটুথের স্বাভাবিক বিষয়।

## সতর্কতা

স্পিকারে চালাবেন না — সাউন্ড আবার মাইকে ঢুকে তীব্র বিপ শব্দ (ফিডব্যাক) হবে। ব্লুটুথ হেডফোনে কিছুটা ডিলে হতে পারে।
